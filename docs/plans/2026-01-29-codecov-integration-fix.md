# Codecov Integration Fix Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Fix Codecov integration by updating GitHub Actions workflow to use v5, add codecov.yml configuration, and ensure proper coverage report generation.

**Architecture:**
1. Update `.github/workflows/ci.yml` to use codecov-action@v5 with explicit token and slug
2. Add `codecov.yml` configuration file for coverage thresholds and path ignores
3. Add `[tool.coverage]` section to `pyproject.toml` for pytest-cov settings
4. Fix coverage report generation to produce XML (not just HTML)

**Tech Stack:** GitHub Actions, Codecov v5, pytest-cov, coverage.py

## Task 1: Add codecov.yml Configuration File

**Files:**
- Create: `codecov.yml`

**Step 1: Create codecov.yml with proper configuration**

```yaml
# Codecov configuration
# See https://docs.codecov.com/docs/codecov-yaml

coverage:
  status:
    project:
      default:
        target: 80%
        threshold: 1%
        base: auto
        if_ci_failed: error
    patch:
      default:
        target: 75%
        threshold: 5%
        base: auto
        if_ci_failed: error

ignore:
  - "*/tests/*"
  - "*/test_*.py"
  - "*/__pycache__/*"
  - "*/site-packages/*"
  - "*/.*cache/*"
  - "src/_version.py"  # Auto-generated by hatch-vcs

comment:
  layout: "reach,diff,flags,files"
  behavior: default
  require_changes: false
  require_base: false
  require_head: true

github_checks:
  annotations: true
```

**Step 2: Commit**

```bash
git add codecov.yml
git commit -m "feat(ci): add codecov.yml configuration

- Set project coverage target: 80%
- Set patch coverage target: 75%
- Ignore test files and generated code
- Enable GitHub annotations for PR comments"
```

## Task 2: Add [tool.coverage] to pyproject.toml

**Files:**
- Modify: `pyproject.toml` (append to end of file)

**Step 1: Add coverage configuration to pyproject.toml**

Add this section at the end of `pyproject.toml` (after `[tool.mypy]` section):

```toml
[tool.coverage.run]
source = ["src"]
omit = [
    "*/tests/*",
    "*/test_*.py",
    "*/__pycache__/*",
    "*/.*cache/*",
    "src/_version.py",  # Auto-generated by hatch-vcs
]
branch = true

[tool.coverage.report]
exclude_lines = [
    "pragma: no cover",
    "def __repr__",
    "raise AssertionError",
    "raise NotImplementedError",
    "if __name__ == .__main__.:",
    "if TYPE_CHECKING:",
    "@abstractmethod",
    "@abc.abstractmethod",
]
precision = 2
show_missing = true
skip_covered = false

[tool.coverage.html]
directory = "htmlcov"
```

**Step 2: Run tests to verify configuration is valid**

Run: `uv run pytest tests/unit --cov=src --cov-report=xml --cov-report=term-missing -q`
Expected: Tests pass, `coverage.xml` file created

**Step 3: Commit**

```bash
git add pyproject.toml
git commit -m "feat(ci): add pytest-cov configuration to pyproject.toml

- Set coverage source directory to src/
- Exclude test files and generated code
- Enable branch coverage
- Configure exclude lines for common patterns"
```

## Task 3: Update GitHub Actions Workflow for Codecov v5

**Files:**
- Modify: `.github/workflows/ci.yml:90-103`

**Step 1: Update the coverage report generation step**

Replace lines 90-94 in `.github/workflows/ci.yml`:

```yaml
      - name: Generate coverage report (unit tests only)
        run: |
          echo "→ Ensuring pytest-cov is installed..."
          uv add --group dev pytest-cov 2>/dev/null || true
          uv run pytest tests --cov=src --cov-report=html --cov-report=term-missing -m unit
```

With:

```yaml
      - name: Generate coverage report (unit tests only)
        run: |
          echo "→ Generating coverage with XML report for Codecov..."
          uv run pytest tests --cov=src --cov-report=xml --cov-report=html --cov-report=term-missing -m unit
```

**Step 2: Update the Codecov upload step to v5**

Replace lines 96-103 in `.github/workflows/ci.yml`:

```yaml
      - name: Upload coverage to Codecov
        if: matrix.python-version == '3.12'
        uses: codecov/codecov-action@v4
        with:
          file: ./coverage.xml
          flags: unittests
          name: codecov-umbrella
          fail_ci_if_error: false
```

With:

```yaml
      - name: Upload coverage to Codecov
        if: matrix.python-version == '3.12'
        uses: codecov/codecov-action@v5
        with:
          token: ${{ secrets.CODECOV_TOKEN }}
          slug: CedarVerse/vandamme-proxy
          files: ./coverage.xml
          flags: unittests
          name: codecov-python-3.12
          fail_ci_if_error: false
          verbose: true
```

## Task 4: Update Makefile Coverage Target to Generate XML

**Files:**
- Modify: `Makefile:398-411`

**Step 1: Update the coverage target to generate XML**

Replace lines 398-411 in `Makefile`:

```makefile
coverage: ## Run tests with coverage report
	@printf "$(BOLD)$(CYAN)Running tests with coverage...$(RESET)\n"
	@printf "$(CYAN)→ Ensuring pytest-cov is installed...$(RESET)\n"
	@$(UV) add --group dev pytest-cov 2>/dev/null || true
	@# Check if server is running, if so run all tests, otherwise run only unit tests
	@if curl -s --max-time 2 --connect-timeout 1 http://localhost:$(PORT)/health > /dev/null 2>&1 || \
	   curl -s --max-time 2 --connect-timeout 1 http://localhost:18082/health > /dev/null 2>&1; then \
		printf "$(YELLOW)Server detected, running coverage on all tests...$(RESET)\n"; \
		$(UV) run $(PYTEST) $(TEST_DIR) --cov=$(SRC_DIR) --cov-report=html --cov-report=term-missing; \
	else \
		printf "$(YELLOW)Server not running, running coverage on unit tests only...$(RESET)\n"; \
		$(UV) run $(PYTEST) $(TEST_DIR) --cov=$(SRC_DIR) --cov-report=html --cov-report=term-missing -m unit; \
	fi
	@printf "$(GREEN)✓ Coverage report generated in htmlcov/$(RESET)\n"
```

With:

```makefile
coverage: ## Run tests with coverage report
	@printf "$(BOLD)$(CYAN)Running tests with coverage...$(RESET)\n"
	@printf "$(CYAN)→ Generating coverage reports (XML + HTML)...$(RESET)\n"
	@# Check if server is running, if so run all tests, otherwise run only unit tests
	@if curl -s --max-time 2 --connect-timeout 1 http://localhost:$(PORT)/health > /dev/null 2>&1 || \
	   curl -s --max-time 2 --connect-timeout 1 http://localhost:18082/health > /dev/null 2>&1; then \
		printf "$(YELLOW)Server detected, running coverage on all tests...$(RESET)\n"; \
		$(UV) run $(PYTEST) $(TEST_DIR) --cov=$(SRC_DIR) --cov-report=xml --cov-report=html --cov-report=term-missing; \
	else \
		printf "$(YELLOW)Server not running, running coverage on unit tests only...$(RESET)\n"; \
		$(UV) run $(PYTEST) $(TEST_DIR) --cov=$(SRC_DIR) --cov-report=xml --cov-report=html --cov-report=term-missing -m unit; \
	fi
	@printf "$(GREEN)✓ Coverage reports generated: coverage.xml, htmlcov/$(RESET)\n"
```
